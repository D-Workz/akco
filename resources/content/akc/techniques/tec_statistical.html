Statistical

Statistical approaches are internal, data-driven methods for validating or predicting knowledge graph (KG) assertions. They rely on statistical distributions of selected features, such as property-value literals or graph structure characteristics, including the types of entities and their relationships.

Figure: Detecting Outliers in Literal Values

Figure 1 illustrates how outliers in literal property-value assertions can be detected using the Interquartile Range (IQR). The example shows the log10 population values of cities in the knowledge graph. The boxplot highlights:

  • The middle 50% of the values (IQR) in a shaded box.
  • The median as a line inside the box.
  • Whiskers that show acceptable value ranges based on data distribution.

In the example, the city beijing exceeds the upper whisker and is therefore flagged as an outlier. Approaches like those by [Wienand et al., 2014] and [Fleischhacker et al., 2014] apply this concept to detect numerical errors. Additional knowledge-driven methods, such as semantic grouping or comparison with external graphs, are used to validate whether the outlier is truly an error.

Figure: Structural Statistics for Outlier Detection and Type Prediction

Figure 2 shows two matrices that represent the distribution of subject and object types across properties. Each cell indicates how frequently a type (row) is used with a property (column), helping detect unusual or missing patterns.

These structural statistics support multiple tasks:

  • Outlier detection: Identifying instances or assertions that deviate from normal usage, such as in SDValidate [Paulheim et al., 2014] or [Debattista et al., 2016].
  • Type prediction: Inferring the type of untyped nodes by comparing their relation patterns to known distributions. For example, if an untyped instance uses hasCapital, which is predominantly used by Countries, its type can be inferred as Country.

Approaches like SDType [Paulheim et al., 2013], [Sleeman et al., 2013], and SLCN [Melo et al., 2017] use statistical measures (e.g., property frequencies, defining properties) and supervised learning to improve prediction accuracy. Some methods assign each class a dedicated classifier for better granularity.

Entity Mapping with Statistical Similarity

The COLIBRI framework [Ngonga et al., 2014] uses unsupervised machine learning to map entities across knowledge graphs. It uses a voting mechanism and average similarity to detect inconsistencies or suggest corrections for equality and property-value assertions.

In summary, statistical approaches are effective in structured and complete domains but require safeguards to avoid reinforcing data biases. Future developments aim to improve robustness and integrate knowledge-driven enhancements.
