Path-Based Approaches

Path-based approaches are internal, data-driven methods that validate property-value assertions by analyzing graph structure. A path is an alternative subgraph connecting the subject and object of an assertion. These paths may be directed (following edge direction) or undirected (allowing traversal in both directions).

Directed paths typically reflect semantic relationships more accurately. Some methods use the ontology to identify schema-level paths based on reasoning and predicate relatedness — a metric that measures how often predicates co-occur in context [95]. Paths are evaluated by:

  • Frequency: How often a path pattern is observed.
  • Specificity: How narrowly a path applies, with more specific paths connecting fewer nodes and carrying more information.

Supervised learning approaches, such as PredPath and OGFC, use labeled assertions to learn discriminative or supportive path patterns:

  • PredPath: Learns predicate-specific paths that uniquely identify a predicate's semantics [96].
  • OGFC: Combines pattern mining with semantic similarity from ontologies (e.g., synonyms, subclasses) to support or refute assertions [97].

Unsupervised approaches extract paths up to a certain depth without labeled data. They rely on general structural patterns.

Extended Path-Based Methods

Some methods refine the path-based validation using additional semantic cues:

  • Relational Knowledge Linker: Introduces a path cost metric. It prefers paths that go through specific (less-connected) nodes rather than general nodes with many relations, which may be too broad to validate specific facts [101].
  • COPAAL: Integrates RDFS semantics such as domain and range restrictions. It also compares path directionality and concludes that undirected paths outperform directed ones due to their broader reach. However, this flexibility can also lead to false positives when validating erroneous assertions.

Overall, path-based approaches offer powerful, structure-aware mechanisms for assertion validation. Their performance depends on the number, direction, and specificity of the paths connecting assertion nodes.
