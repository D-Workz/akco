Most knowledge graphs use three types of assertions:

  • Instance assertion
  • Property-value assertion
  • Equality assertion

These assertions may contain semantic or syntactic errors, which describe the error nature. The error source refers to the specific assertion that is incorrect.

The error type is determined by combining the error source and error nature. It identifies which entity (subject, predicate, or object) in the triple is erroneous.

The erroneous entity is identified through specific operands, which are defined by the corresponding operator.

How can I represent more specific errors, like errors in tail verticals?

Errors are a subclass of skos:concept to highlight the fact that error can be relatable, for example via skos:narrower or skos:broader. To annotate a tail vertical, one can define a new error of type tail vertical and then relate it via skos:narrower to an existing error. 

    
:errPVSemSemWrong a :Error ;
  rdfs:label "errPVSemSemWrong"@en ;
  rdfs:comment "Error is of semantic nature, afflicting property-value assertions, and causing a semantically wrong property-value assertion."@en ;
  :errorSource "Property-value assertion"@en ;
  errorNature "Semantic"@en ;
  errorType "Assertion is semantically wrong"@en ;
  skos:narrower errTailVertical .

errTailVertical a Error ;
  rdfs:label "errTailVertical"@en ;
  rdfs:comment "A tail vertical is a domain that is not well covered by a knowledge graph. Entities in these domains are typically sparse."@en ;
  skos:broader errPVSemSemWrong .
