Changes from version 1.0.0 to version 1.1.0

Nampespaces have been merged, and ontology metadata has been added to serve FAIR princibles.

  • Changed namespace from terms to dcterms for http://purl.org/dc/terms/
  • Changed namespace from dc to dcterms for wrongly assginged http://purl.org/dc/elements/1.1/
  • Added missing version URI, for FAIR support
  • Changed versioning format to X.Y.Z, for FAIR support
  • Changed dcterms:issued to dcterms:created, since correct semantics.
  • Changed dcterms:creator property value from string to ORCID URI
  • Added dcterms:contributor, since FAIR recommendation.
  • Added versioning in general
