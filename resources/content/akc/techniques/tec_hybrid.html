Hybrid

Hybrid approaches combine multiple knowledge graph cleaning techniques to produce more reliable results or to address complex tasks that exceed the scope of a single method. They are especially effective in scenarios involving context ambiguity, tail verticals, or systematic errors.

Figure: Symbolic Workflow of a Hybrid Approach

Figure 1 visualizes a generalized hybrid approach. These systems typically share two common features:

  1. Parallel Application: Multiple cleaning techniques are applied in parallel. Each technique contributes additional context.
  2. Combined Evaluation: The individual results are merged to produce a final decision—usually a correctness score and a suggested correction.

The illustrated example shows two independent validation results being combined to assess a single assertion. The integration step must reconcile possibly conflicting evidence, a key challenge for hybrid systems.

Hybrid Validation Approaches

  • ExFaKT [Gad et al., 2017]: Combines rule mining (AMIE+) and verbalization with text corpora and another KG. It uses PATTY [Nakashole et al., 2012] for paraphrase dictionaries and alias detection.
  • HybridFC [Qudus et al., 2022]: Integrates verbalization, path-based, and embedding-based approaches. It transforms evidence into vectors and uses a neural network to predict correctness scores.

Hybrid Correction Approaches

  • MTM [Yu et al., 2014]: Merges the output of multiple methods, weighing them against the trustworthiness of external sources.
  • Chen et al. [Chen et al., 2021]: Combines lexical similarity, embeddings, lookup services (e.g., DBpedia Lookup), and constraint-based validation.
  • CoCKG [Melo et al., 2020]: Uses PaTyBRED [Melo et al., 2017] to detect errors, then corrects them using Wikipedia disambiguation pages and string matching.
  • Fan et al. [Fan et al., 2019]: Combines reasoning, integrity constraints, and crowdsourcing. It defines instance identity using keys [Fan et al., 2015] and graph structure using GEDs [Fan et al., 2019b].

Hybrid Approaches for Complex Tasks

  • FACTY: Validates assertions in long-tail domains by combining evidence from KGs, web tables [Cafarella et al., 2008], and Google query logs.
  • TISCO [Rula et al., 2019]: Focuses on temporal scoping. It integrates DeFacto >[Gerber et al., 2015], DBpedia, and content negotiation [Fielding et al., 1999] to handle time-based assertions.
  • Paulheim (2015) [Paulheim et al., 2015]: Targets systematic errors using ontology enrichment (via DOLCE-Zero [Masolo et al., 2003]), reasoning, clustering (Manhattan distance), and crowdsourcing.

These hybrid systems demonstrate the potential of combining multiple techniques to address a wider range of cleaning challenges. However, their complexity makes them harder to implement and maintain. Future work could aim to simplify data integration and orchestration in such frameworks.
