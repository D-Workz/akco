Syntatic

Syntactic cleaning approaches are external and knowledge-driven, comparing the serialization of a knowledge graph (KG) to a defined syntax specification. Similar to grammar parsing in text or schema validation in relational databases, these approaches ensure that a KG's structure follows serialization rules, such as those for Turtle or RDF/XML.

Figure: Parser-Based Syntax Validation

Figure 1 illustrates how a parser processes a KG serialization in Turtle format to identify syntactic violations. The process involves three steps:

  1. Parser Configuration: The parser can be a standard tool like Apache Jena [McBride, 2002], which supports various RDF formats (e.g., Turtle, RDF/XML), or a custom-built parser using tools such as CUP.
  2. Parsing Input: A KG serialization is passed to the parser and matched against the syntax specification line by line.
  3. Error Reporting: Violations are logged in a report. The parser may either continue checking or stop at the first detected error.

In the example, a missing end-of-statement symbol on Line 3 is flagged as a syntactic violation.

Parser Tools and Online Validators

Several tools exist for syntax validation:

  • VRP: Parses RDF and RDFS serializations, stopping at the first error [Tolle et al., 2000].
  • Validation Service: A W3C online RDF validator [Online Tool].
  • IDLab Turtle Validator: Offers extended support for literal types and is available online [Online Tool].

Scalable Parsers with Correction Features

Some approaches focus not only on detection but also on large-scale correction:

  • LOD Laundromat: Scales to large graphs and uses SWI Prolog [Beek et al., 2014]. It supports formats like Turtle, JSON-LD, and RDF/XML. It detects issues like:
    • Missing punctuation (e.g., dots or semicolons)
    • Undefined or malformed IRIs
    • Missing or unmatched tags
  • RDF-Doctor: Segments graphs into chunks for parallel parsing. It reports corrected errors and those that remain unresolved [Hemid et al., 2019].

While these tools work on KG serializations, no current approach directly validates or repairs entity-level syntax within the graph structure itself. This presents an opportunity for future research to eliminate the detour through serialization and address syntactic errors directly at the entity level.
