How can different errors be represented?

Errors can be are modeled using akco:Error. A human readable description can be provided using rdfs:comment. An error is defined, by its error source, nature, and type, which can be defined using the properties:

  • akco:errorSource, denotes the type of assertion that is erroneous, e.g., wrong instance, property-value, or equality assertion.
  • akco:errorNature, denotes if an error is of semantic or syntactic nature.
  • akco:errorType, denotes the actual type of error, resulting from source, and nature.

The Error identifiers use the following syntax: "err"+ErrorSource+ErrorNature+ErrorType

  • ErrorSource can have the values:
    • PV(Property-value)
    • I (Instance)
    • E (Equality)
  • ErrorNature can have the values:
    • Sem(Semantic)
    • Syn (Syntactic)
  • ErrorType can have values, like:
    • SemWrong(Semantically wrong)
    • NotPIdentID (Not a proper instance identifier)
    • NotADomain (The type of the instance is not supported by the domain specification of a property)
    • NotEType (Not an existing type name)
akco:errPVSemSemWrong a :Error ;
 rdfs:label "errPVSemSemWrong"@en ;
 rdfs:comment "Error is of semantic nature, afflicting property-value assertions, and causing a semantically wrong property-value assertion."@en ;
 akco:errorSource "Property-value assertion"@en ;
 akco:errorNature "Semantic"@en ;
 akco:errorType "Assertion is semantically wrong"@en.

An instance representing a semantical error in a property value assertion, causing the assertion to be semantically wrong.

How can more specific errors be represented, like errors in tail verticals?

To represent a dynamic hierarchical relation of different errors, the class akco:Error is subclass of skos:concept. An error is also a concept that can be related to other concepts. It is therefore possible to specify any type of more specific or general error class and relate them using skos:narrower or skos:broader.

To represent a tail vertical one can define a new error of type tail vertical and then relate it via a matching skos property to an existing error.

akco:errTailVertical a Error ;
  rdfs:label "errTailVertical"@en ;
  rdfs:comment "A tail vertical is a domain that is not well covered by a knowledge graph. Entities in these domains are typically sparse."@en ;
  skos:broader errPVSemSemWrong .

A tail vertical error can be expressed as a more specific type of a semantic error, which can be annotated using SKOS properties.
