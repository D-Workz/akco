The values of property-value assertions in a knowledge graph include both literal values and IRI instances. These values constitute an internal source of background knowledge, reflecting how specific properties are typically used throughout the graph.

The meaning of a value is often dependent on the subset of the graph in which it appears—particularly the set of assertions that share the same property.

Statistical approaches analyze these value distributions to detect outliers, which may signal incorrect assertions. Outliers can include unexpected numerical ranges, rare object types, or inconsistent usage patterns.
