Verbalization-based

Verbalization-based approaches validate property-value assertions using unstructured external sources, such as web documents or text corpora. The goal is to retrieve and analyze evidence that supports or contradicts the assertion.

Figure: Workflow for Verbalization-Based Validation

Figure 14 presents the workflow in three main steps:

  1. Verbalize the Assertion: The assertion is translated into natural language using pattern libraries or neural models. Tools like DeFacto [1] and FactCheck [2] use the BOA pattern library [3] to generate variations of the assertion. However, most BOA patterns do not verbalize facts accurately [4], which highlights a key area for improvement. More recent verbalization techniques rely on neural networks and large language models [5], though none of the reviewed systems have integrated these yet.
  2. Search for Evidence: The verbalized sentence is searched in external sources. Approaches vary:
    • FacTify: Uses embeddings and BM25 for semantic and exact matches [6].
    • S3K: Matches text via pre-built dictionaries [7].
    • FactCheck: Leverages Elasticsearch [8].
    • DeFacto: Uses search engines and filters results by topic coverage and reliability [9].
  3. Analyze the Evidence: Retrieved documents are evaluated for consistency. Some tools (FacTify, S3K) return only the top-k results, requiring external validation. DeFacto and FactCheck go further:
    • DeFacto: Computes a confidence score based on evidence quantity, quality, and probability of correctness.
    • FactCheck: Combines word coherence [10] and topic indicators [9] in a supervised model.

The table in Figure 14 illustrates a key challenge: contradictory evidence. For example, web results indicate that “Sydney is in Florida, USA” and “Sydney is in New South Wales, Australia.” Both are true in isolation, but without contextual understanding, automated systems may misclassify the assertion. This emphasizes the need for contextual graph construction and contextual verbalization.

Limitations and Opportunities

Despite their potential, no current verbalization-based approaches validate assertions using Large Language Models (LLMs) like ChatGPT or T5. These models could assist in verbalization, search, or analysis but must overcome issues such as hallucination—producing plausible yet incorrect facts [11]. Addressing this would require mechanisms for grounding outputs and ensuring factual reliability.
